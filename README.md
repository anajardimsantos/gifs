# Animações GIF

Repositório com animações e vídeos interessantes.

## Vídeo: remoção de figurinha (We Are Tunisia)

Este projeto gera um vídeo MP4 de 4 segundos simulando a remoção suave de uma figurinha no álbum **We Are Tunisia**.

### Como gerar o vídeo

```bash
python -m pip install -r requirements.txt
python create_tunisia_sticker_video.py
```

Saída gerada:

- `we_are_tunisia_sticker_removal.mp4`
